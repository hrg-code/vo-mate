# AI 自媒体工作台组件规范

版本：v0.1  
日期：2026-05-09  
目标：定义 React Web 工作台的基础组件、业务组件、AI 组件和数据组件规范。

## 1. 组件设计原则

- 组件服务工作流，不做装饰堆叠。
- 业务组件必须表达数据含义和下一步动作。
- AI 组件必须展示依据、状态和反馈入口。
- 数据组件必须支持空、加载、错误、权限不足状态。
- 交互控件优先使用熟悉模式：按钮、菜单、Tabs、表格、Drawer、Tooltip。
- 图标优先使用 `lucide-react`。
- 默认圆角不超过 `8px`。

## 2. 组件分层

| 层级 | 示例 | 说明 |
| --- | --- | --- |
| 基础组件 | Button, Input, Select, Tabs | 通用 UI 基础 |
| 布局组件 | AppShell, PageHeader, SplitPane | 页面结构 |
| 数据组件 | MetricCard, DataTable, ChartPanel | 数据展示 |
| AI 组件 | AIInsightPanel, EvidenceDrawer | AI 结果和依据 |
| 内容组件 | VideoRow, ScriptEditor, TopicCard | 业务对象 |
| 反馈组件 | Toast, Modal, TaskStatus | 状态和确认 |

## 3. 基础组件

## 3.1 Button

### 类型

| 类型 | 用途 |
| --- | --- |
| `primary` | 页面主操作 |
| `secondary` | 次级操作 |
| `ghost` | 工具栏操作 |
| `danger` | 删除、断开连接 |
| `icon` | 搜索、筛选、复制、刷新等 |

### 规则

- 每个页面最多一个主按钮组。
- 图标按钮必须有 Tooltip。
- 危险按钮必须有确认。
- Loading 状态禁用重复点击。

### 常用图标

| 操作 | 图标 |
| --- | --- |
| 搜索 | `Search` |
| 筛选 | `Filter` |
| 刷新 | `RefreshCw` |
| 复制 | `Copy` |
| 保存 | `Save` |
| 下载 | `Download` |
| 删除 | `Trash2` |
| 生成 | `Sparkles` |
| 查看依据 | `ListChecks` |

## 3.2 Input

### 类型

- 单行输入。
- 多行输入。
- 搜索输入。
- 数字输入。
- 标签输入。

### 状态

- 默认。
- 聚焦。
- 禁用。
- 错误。
- 成功。
- 加载。

### 规则

- 必填字段显示清晰错误。
- 长文本输入显示字数。
- SEO 标题输入显示平台长度限制。

## 3.3 Select / Combobox

用途：

- 平台选择。
- 账号选择。
- 时间范围。
- 内容状态。
- 话题分类。

规则：

- 选项超过 8 个时支持搜索。
- 多选用 checkbox list。
- 平台选择应显示平台图标和账号名。

## 3.4 Tabs

用途：

- 视频详情。
- SEO 平台切换。
- 报告类型切换。

规则：

- Tab 文案短。
- 当前 Tab 状态明显。
- Tab 内数据懒加载。
- 不使用多层嵌套 Tabs。

## 3.5 Tooltip

用途：

- 图标按钮解释。
- 指标定义。
- 置信度说明。

规则：

- 简短解释，不放长报告。
- 复杂说明使用 Popover 或 Drawer。

## 4. 布局组件

## 4.1 AppShell

### 组成

- `TopBar`
- `SideNav`
- `MainContent`
- `RightPanel`

### Props

```ts
type AppShellProps = {
  workspaceId: string;
  activeRoute: string;
  sideNavCollapsed: boolean;
  rightPanel?: React.ReactNode;
};
```

### 行为

- 侧边栏可收起。
- 右侧面板可固定或关闭。
- 顶栏固定。
- 主内容区域独立滚动。

## 4.2 PageHeader

### 内容

- 标题。
- 副标题。
- Breadcrumb。
- 筛选器。
- 主操作。

### 示例

```text
视频库
查看所有平台内容表现，筛选高潜力视频并生成复盘
[平台筛选] [时间范围] [同步数据]
```

## 4.3 RightPanel / Drawer

用途：

- AI 建议。
- 依据详情。
- 快速筛选。
- 内容详情预览。

规则：

- 桌面端可固定。
- 窄屏转 Drawer。
- 打开后焦点进入面板。
- 关闭不丢失主页面状态。

## 5. 数据组件

用途：展示核心指标。

### 字段

- 指标名。
- 当前值。
- 单位。
- 环比/同比。
- 趋势。
- 状态。

- 增长：teal。

- 批量选择。

## 10. 反馈组件

## 10.1 Toast

用途：

- 短反馈。
- 任务创建成功。
- 保存成功。
- 错误提示。

规则：

- 成功 Toast 3 秒自动消失。
- 错误 Toast 保留操作入口。
- 长任务不只依赖 Toast，应进入 Task Center。

## 10.2 ConfirmDialog

用于危险操作。

### 必填内容

- 操作对象。
- 后果说明。
- 取消按钮。
- 确认按钮。

严重操作可要求输入确认文本。

## 10.3 EmptyState

### 结构

- 简短标题。
- 原因说明。
- 下一步按钮。
- 可选次级操作。

示例：

```text
还没有复盘报告
先选择一条视频生成复盘，系统会从指标、口播和搜索词中提炼经验。
[去视频库]
```

## 10.4 ErrorState

### 结构

- 错误标题。
- 用户可读说明。
- 重试按钮。
- 查看技术详情。

## 13. 组件验收清单

每个组件完成前检查：

- 是否有 loading 状态。
- 是否有 empty 状态。
- 是否有 error 状态。
- 是否支持键盘操作。
- 图标按钮是否有 tooltip。
- 长文本是否截断或换行合理。
- 是否能在 320px 宽度下不重叠。
- 是否有必要的 aria 属性。
- 是否没有卡片套卡片。
- 是否符合页面主任务。
